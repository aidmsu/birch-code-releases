# Birch Code — Releases

Distribution channel for [Birch Code](https://getbirch.dev) — a Git UI for parallel AI workflows on macOS, Windows, and Linux.

This is a release-only repository: it hosts the GitHub Releases that the landing page and in-app update checks pull from. The product itself is closed-source for now.

## Download

- [**Latest release →**](https://github.com/aidmsu/birch-code-releases/releases/latest)
- [All releases →](https://github.com/aidmsu/birch-code-releases/releases)
- [**getbirch.dev**](https://getbirch.dev) — auto-detects your OS and architecture, links directly to the right binary

## Platforms

Each release ships binaries for every supported platform:

| Platform              | File pattern                                |
| --------------------- | ------------------------------------------- |
| Windows x64           | `*-win-x64.zip`                             |
| macOS Intel           | `*-osx-x64.dmg`                             |
| macOS Apple Silicon   | `*-osx-arm64.dmg`                           |
| Linux x64             | `*-linux-x64.tar.gz` / `.AppImage` / `.deb` |
